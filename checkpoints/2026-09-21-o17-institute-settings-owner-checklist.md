## وضعیت فعلی روی دیتابیس توسعه (کپی `/tmp/o17.db`)
```
select count(*) from institute_settings → 0      (هیچ ردیفی وجود ندارد)
device_tokens                            → 0
```
⇒ تا وقتی مدیر یک بار صفحهٔ «تنظیمات آموزشگاه» را ذخیره نکند، **همهٔ مقادیر از defaultهای مدل** می‌آید؛
و آن defaultها داده‌ی نمونه‌ی جعلی‌اند (آدرس «تهران، خیابان شریعتی…»، تلفن `02122222222`، ایمیل
`info@kharazmi.com`، شماره کارت `۶۰۳۷۹۹۷۹۷۹۷۹۷۹۷۹`). این مقادیر مستقیم روی **رسید/فاکتور چاپی** و
**پورتال ولی** می‌روند.
