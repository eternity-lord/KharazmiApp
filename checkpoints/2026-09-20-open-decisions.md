## پیوست: SQL سنجش کلاس‌های نامرئی (B5 — فقط خواندن، برای اجرای دستی روی DB واقعی)

```sql
-- کلاس‌هایی که نه فعال‌اند نه آرشیو (is_deleted IS NULL) ⇒ در هیچ لیستی دیده نمی‌شوند
SELECT id, title, code, teacher_id, branch_id FROM courses WHERE is_deleted IS NULL;
-- همین سنجش برای ثبت‌نام/جلسه/شاگرد/معلم/تراکنش در صورت نیاز
SELECT 'enrollments' AS t, COUNT(*) FROM enrollments WHERE is_deleted IS NULL
UNION ALL SELECT 'session_logs', COUNT(*) FROM session_logs WHERE is_deleted IS NULL
UNION ALL SELECT 'students',     COUNT(*) FROM students     WHERE is_deleted IS NULL
UNION ALL SELECT 'teachers',     COUNT(*) FROM teachers     WHERE is_deleted IS NULL;
```
اگر خروجی خالی بود (مثل DB فعلی: `courses` بدون NULL)، هیچ اقدامی لازم نیست.
